Adds an advisory Flood outlook conditional on an already-confirmed active event. It provides `predict_active_event`, a cached site-aware backend adapter, typed context/evidence validation, and an excluded `predict_site` score component. Recorded event ends cannot authorize work or clear alerts; no route or frontend integration is added.

Training uses pinned NOAA 2021-2025 data and purges complete episodes whose outcomes cross fitting/selection boundaries. Corrected 2024 validation favors the conditional KM baseline, which stays default. Weather is a separate matched-sample ERA5 experiment with production eligibility false. Source/model checksums, pinned Windows setup, reproducible provisioning, calibration/duration metrics, and a copy-ready integration handoff are included under `ml/`.

Validation: 82 tests passed (81 ML, one backend health), compileall and diff checks passed, and a new environment rebuilt the identical model hash. Full corrected evaluation completed in about eight seconds; bounded 1/4/8/12-worker benchmarks favor one worker. Paired curve reuse measured 3.20x prediction speedup, with no claim of a measured full-run speedup. Frontend checks were unavailable because this shell has no Node/npm.

Limitations: only Flood is supported; trend remains unknown; regional event records do not verify site exposure; duration errors remain large; 2025 was already inspected; ERA5 historical operational availability is unverified. All outlooks remain production-ineligible advisory evidence. Rudra's optional route contract and authorization remain pending.
